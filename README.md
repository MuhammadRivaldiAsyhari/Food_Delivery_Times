# 🚚 Prediksi Waktu Pengiriman Makanan

Proyek ini bertujuan untuk **memprediksi estimasi waktu pengiriman makanan** menggunakan beberapa model Machine Learning, seperti:

- 🔹 Linear Regression  
- 🌲 Decision Tree  
- 🌳 Random Forest  
- 🛠️ Random Forest (Tuned)

Aplikasi ini dibangun menggunakan **Streamlit** agar pengguna dapat berinteraksi langsung dan mencoba prediksi berdasarkan data input mereka sendiri.

---

## 📦 Fitur Aplikasi

- Input data pengiriman seperti:
  - Umur kurir
  - Rating kurir
  - Jarak dan koordinat lokasi restoran & tujuan
  - Kondisi cuaca & jalan
  - Jumlah pengantaran
- Memilih model ML yang akan digunakan
- Menampilkan hasil prediksi waktu pengiriman
- UI yang sederhana dan interaktif dengan Streamlit
